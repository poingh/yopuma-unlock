# 有谱么播放限制解除

解除 [有谱么](https://yopu.co) 乐谱 15 秒播放限制的 Tampermonkey 用户脚本。

## 安装
1. 安装 Tampermonkey 浏览器插件
2. 点击 [安装链接](https://cdn.jsdelivr.net/gh/poinghy/yopuma-unlock/yopu-unlock.user.js)
## 功能
- 自动拦截 15 秒限制定时器
- 阻止自动暂停
- 播放限制已解除提示
